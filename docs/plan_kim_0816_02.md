## 4. ⚠️ 시안 불일치 — 이렇게 가정하고 구현합니다

시안이 아직 정리 중(`"디자인 짜잘한 거 맞추기"`)이라 아래 4개가 어긋나 있습니다. **다르면 알려주세요.**

| # | 시안 상태 | 구현 가정 |
| 1 | ~~**온보딩3에만 인디케이터가 없음**~~ | **정정**: 시안 오류가 아니었다. 좌표를 확인하니 인디케이터(y=768)와 CTA(y=736~807)가 **화면 하단 같은 자리를 공유**한다. 즉 1·2페이지는 인디케이터, 마지막 페이지는 CTA가 그 자리를 대신하는 의도된 설계다. **시안 그대로 구현.** |
| 2 | **온보딩3에만 CTA 버튼**, 1·2에는 없음 | 1·2는 스와이프로만 이동, 3에서 `[운동하기]` 노출. **건너뛰기 버튼은 시안에 없어 만들지 않음** |
| 3 | 스플래쉬에 `"채린님"` — 로그인 전인데 이름을 알고 있음 | 닉네임을 못 얻는 상태이므로 **`"스파크가 회원님과 어울리는…"`으로 렌더**하고, 닉네임 주입 가능하도록 props로 설계 |
| 4 | `스플래쉬` 이름 프레임이 2개 (`64:398`, `75:2804`) | `75:2804`("준비가 끝났어요!")는 **설문 완료 화면**으로 판단 → 이번 범위 제외 |
