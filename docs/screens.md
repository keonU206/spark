## 7. 기획 확인이 필요한 항목 정리

### A. 시안에 없어 제가 만든 것
| 항목 | 위치 |
|------|------|
| **운동 상세 화면 전체** | `workout/[id]` |
| 마이페이지 진입 버튼 | 홈 우측 상단 |
| 로그아웃 | 마이페이지 |
| 알림 시간대 선택 시트 (프리셋 10개) | 알림 설정 |
| 설문 드롭다운 선택지 목록 | 설문조사 |
| 설문 선택 UI (하단 시트) | 설문조사 |
| `모임 만들기`/`코드로 참여` 버튼 위치 | 커뮤니티 |

### B. 시안과 다르게 한 것
| 항목 | 시안 | 구현 | 이유 |
|------|------|------|------|
| 스플래쉬 문구 | "채린님과" | "당신과" | 로그인 전이라 이름을 모름 (요청 반영) |
| 기록 탭 헤더 | 뒤로가기 있음 | 제거 | 탭 루트라 돌아갈 곳이 없음 |
| 연속 출석 캘린더 | 요일 헤더 3줄로 깨짐 | 정상 7열 | 시안 미완성으로 판단 |
| 앱 이름 | "홈트 루틴" 잔재 | "스파크" | 본문에 스파크로 쓰여 있어 통일 |
| 탭 활성 표시 | 항상 "모임"만 진하게 | 실제 선택 탭 | 컴포넌트 복사 흔적으로 판단 |

### C. 아직 못 만든 것
- 모임 피드 **글 작성** (시안 없음)
- 피드 **댓글 달기** (표시만 있고 입력 UI 없음)
- 구글 로그인 실연동 (클라이언트 ID 필요)
- **자세 인식 실제 추론** (모델 파일 필요)

### D. 용어 불일치
- **`재촉하기`**(홈·커뮤니티·모임현황) vs **`잡도리`**(알림 설정)
  → 시안이 그렇게 되어 있고 "화면별 시안 그대로" 지침을 따랐으나,
  사용자 입장에서는 같은 기능이 두 이름으로 보입니다. **통일 여부 결정 필요**
