## 2. Phase A — 기반 다지기 (백엔드 없이 지금 가능)

화면이 28개로 늘어나면서 같은 코드가 반복되고 있다. 화면을 더 늘리기 전에 정리하는 편이 싸다.

- [ ] **서버 상태 관리 도입** — 현재 모든 화면이 `useEffect` + `useState` + `alive` 플래그를 직접 반복한다(로딩·에러·정리 로직 중복 28곳). TanStack Query로 교체하면 캐시·재시도·중복요청 제거가 따라온다
- [ ] **HTTP 클라이언트** — `axios` + 인터셉터(토큰 주입, 401 재발급, 에러 정규화)
- [ ] **에러 처리 통일** — 지금은 화면마다 `setError(문자열)` → 공통 에러 화면/토스트로
- [ ] **Pretendard 폰트 번들** — 현재 시스템 폰트다. Figma 변수는 `SF Pro Text`인데 Android에 없다. `assets/fonts/`에 otf 배치 → `expo-font`로 로드 → `src/theme/tokens.ts`의 `fontFamily`만 채우면 전체 반영
- [ ] **폼 검증** — `react-hook-form` + `zod`. 지금은 로그인·회원가입·설문·모임생성이 각자 수동 검증
- [ ] **로딩/빈 상태** — `ActivityIndicator` 대신 스켈레톤, 목록 빈 상태 문구 정리
- [ ] **무한 스크롤 연결** — `getExercises`는 `nextCursor`를 이미 반환하는데 운동 목록이 첫 페이지만 쓴다
