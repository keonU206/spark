## 1. 지금 당장 할 수 있는 것 — 폰에 설치해서 확인

빌드가 됐으므로 **실기기 검증이 가능하다.** 이번 세션 내내 막혀 있던 부분이다.

```
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

설치 후 개발 서버를 붙인다:
```
npx expo start --dev-client
```

**여기서 확인할 것** — 실기기에서만 알 수 있는 것들:
- [ ] 폰트가 시안과 얼마나 다른지 (지금 시스템 폰트)
- [ ] SafeArea·탭바 위치가 실제 기기에서 맞는지
- [ ] 카메라 권한 요청이 뜨는지
- [ ] 운동 진행 화면에서 카메라 프리뷰가 나오는지

## 2. C 마무리 — 자세 인식 실제 연결

빌드는 됐지만 **아직 추론은 mock이다.** 남은 것:

      (라이선스 확인 필요. 임의로 내려받지 않았다)
- [ ] `CameraStage`에 실제 `<Camera>` 컴포넌트 + 프레임 프로세서 연결

- [ ] 모델 출력 → `Pose` 변환 (`KEYPOINT_NAMES` 순서 그대로)
- [ ] 성능 확인 — 목표 프레임률, 발열, 배터리
- [ ] 자세 판정 로직 — 관절 각도로 정확/부정확, 횟수 카운팅
- [ ] 음성 안내 (시안에 "음성 교정 안내" 명시)

> `CameraStage`가 카메라 가용 여부를 동적 import로 판단한다.
> **화면 코드는 건드릴 필요가 없다.**
